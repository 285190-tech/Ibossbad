# Game cover artwork

This directory contains locally served WebP thumbnails for the 207 built-in games and app shortcuts in `public/games-catalog.js`. The initial bulk set was selected from web image-search results; local copies let the Games hub render without third-party image requests.

## Provenance and rights

The full set received a visual contact-sheet review; `sources.json` records source pages and match notes for covers corrected in that review. The original bulk selection did not retain per-image source URLs, so the other entries have not been verified against their original source or checked for license/permission. No redistribution rights are asserted by this repository; game names, logos, screenshots, and artwork remain the property of their respective creators and rights holders. Verify permissions before reuse and replace or remove an image if its rights holder requests it.
